# 대사·공격 효과·출력 장치 마무리 (2026-11-12)

## 적용

- 대사를 초당65개 텍스트 요소로 빠르게 표시한다. 한글·결합 문자·서로게이트를 자르지 않는다. 대사창 클릭/Space/Enter는 미완성 문장을 즉시 펼치고, 완성 후 다음 입력에 다음 대사로 간다. Esc/건너뛰기는 기존처럼 장면을 끝낸다. 전투 대사·적 말풍선에도 타이핑이 적용된다.
- 기존 음량·음소거에 따르는 짧은 합성 타이핑 소리를 넣었다. 공백/문장부호는 소리를 내지 않고 최대20회/초로 제한한다. 즉시 펼칠 때 몰아서 재생하지 않는다. GUI Repaint가 같은 프레임에 반복되어도 타이핑 시계를 한 번만 진행한다.
- 대사창 초상에 기존 Tiny Swords 대기 시트를 재생한다. 시간 정지 중에도 움직이며 새 일러스트·폰트·캐릭터를 도입하지 않았다.
- 검사 일반/분기1/분기2는 초승달/보라 회전/주황 강타의 PixelFX 시트를 쓴다. 몸 위치·좌우 방향을 기준으로0.4초에 압축 재생한다. 궁수·폭탄·서리는 몸에서 나오는 발사 효과와 투사체 잔상을 더했다. 연사 이중 섬광, 저격 색, 넓은 폭발 섬광/화염, 서리 고리/결정으로 분기를 구분한다. 공격 횟수·피해·판정·시뮬레이션은 바꾸지 않는다. 적70명 이상에서는 늦은 잔상과 투사체 꼬리를 생략한다.
- 소리 메뉴에서 실제 Windows 활성 출력 이름을 스크롤 목록으로 표시한다. `기본 장치`와 장치 이름을 고르며 새로고침·현재 선택 표시·테스트 소리를 제공한다. 이 앱 PID의 콘솔/멀티미디어 출력만 바꾼다. 마이크·시스템 기본 장치·다른 앱은 바꾸지 않는다. 미연결 장치 선택은 거부하며 적용 실패 시 이전 경로를 복구한다. Web에서는 Windows 전용임을 표시한다.
