- 단계별 생김새:
  - 기본: 파란 팀색의 간단한 장비.
  - 분기: 장비가 늘고 역할이 드러난다.
  - 진화: 장식, 망토, 빛 효과가 더해진다.
- 게임 수치와 역할은 아직 정하지 않았다. 그림을 먼저 만들고, 게임에 넣는 범위는 그림 결과를 보고 따로 정한다.

## 제작 방식 (검증됨: 창병 파일럿)
1. **Gemini 설정:** ego lite에서 gemini.google.com을 열고 "이미지 만들기"를 켠다. 한 대화에서 이어 만들어야 그림체가 유지된다.
2. **참고 이미지:** Tiny 시트를 마젠타 배경에 NEAREST로 확대해 올린다.
   - 대기: `WarriorIdle` 8프레임 4배.
   - 근접 공격: `WarriorAttack` 4프레임 4배.
   - 사격: `ArcherShoot` 8프레임 3배.
   - 시전: `FrostCast` 중 6프레임 3배.
3. **프롬프트는 짧게(약 300자 이하, 한 줄):** 긴 글은 Gemini가 첨부 파일로 바꿔 전송되지 않는다.
   - 대기: "같은 그림체·크기·배치로 새 캐릭터 8프레임 대기, 무기는 모든 프레임 같은 자리, 숨쉬기만 움직임".
   - 공격: "방금 그린 같은 캐릭터로 공격 N프레임".
   - 배경은 완전 단색 #FF00FF, 글자와 바닥 그림자 금지.
4. **입력 방식:** 텍스트는 `keyboard.type`으로 입력하고 Enter로 보낸다. `insertText`나 `fill`은 편집기가 입력으로 인식하지 않는다.
5. **후처리** (`process.py`):
   - 마젠타와 어두운 보라 바닥 그림자를 지운다.
   - 프레임 수만큼 나누고, 같은 배율로 키를 89px(공격 92px)에 맞춘다.
   - 발을 192×192 칸의 (96,137)에 맞추고 32색으로 줄인다. Tiny 검사 시트와 같은 칸 규칙이다.
