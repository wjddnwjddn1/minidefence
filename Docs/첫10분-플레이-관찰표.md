# 잔불의 성채 후보 — 첫10분 플레이

## 실행

`C:\minidefence\Tests\bin\TacticalCandidate\Playtest.cmd`를 실행한다. 이 실행기가 `--tactical-playtest`를 붙여 일반 전투 카드가 있는 규칙4 후보를 연다. exe만 직접 열면 기본 규칙3으로 시작하므로 이 관찰에는 cmd를 사용한다.

기존 플레이판·다운로드는 그대로다. Windows 후보의 Unity PlayerPrefs 저장 대상은 `HKEY_CURRENT_USER\Software\SnometComparison\EmberBastionTacticalCandidate`이며 기존 `EmberBastionUnityComparison` 제품과 분리된다. 관찰을 위해 저장을 삭제할 필요는 없다.

## 해석 원칙

자동 입력 검사 통과와 사람의 재미는 구분한다. 이 한 사람의 관찰을 전체 유저 통계로 취급하지 않는다. 답을 받은 뒤 입력 경로·첫 위기 안내·병과 조합 개선의 우선순위를 판단한다. Windows 적80~99명 구간 성능 측정과 실제 휴대폰 검수는 별도다.
