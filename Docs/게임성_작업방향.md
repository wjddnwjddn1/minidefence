# 게임성 작업 방향과 진행 기록

## 목표

플레이어가 적을 막는 과정에서 병과와 위치를 고르고, 패배한 뒤에는 편성을 바꾸어 다시 시도할 이유를 알 수 있도록 한다. 적 100명 도달 시 패배하는 현재 규칙을 기준으로 한다.

## 작업 원칙

- 게임 규칙과 저장 호환을 확인하고, 기존 플레이 데이터 및 Windows 빌드 경로를 보존한다.
- 배치·강화·대상 우선순위의 결과를 화면에서 이해하기 쉽게 보여준다. 조언은 실제 상태에 근거하며 승리를 보장하는 것으로 표현하지 않는다.
- 수치 변경은 같은 전장·난도·시드에서 후보와 기존 결과를 비교하고, 사람의 플레이 체감을 확인한 뒤 결정한다. 자동 플레이는 재미나 난도 평가를 대신하지 않는다.
- 변경 후 관련 규칙 검사와 빌드를 수행하고, 실제 화면·기기에서 확인하지 못한 항목은 구분해 기록한다.

## 이번 작업: 패배 후 남은 적 안내

기존 결과 카드의 남은 골드, 빈 자리, 강화·배치 안내는 유지한다. 적이 100명에 도달해 패배하면 살아 있는 적의 종류를 세어 가장 많은 종류와 숫자를 결과 카드에 추가한다. 최다 수가 같으면 해당 적 이름을 최대 두 종류까지 보여주고 더 있으면 ‘등’을 표시하며, 전투를 포기한 경우에는 표시하지 않는다. 전투 계산이나 저장 형식은 바꾸지 않는다.

검증: 남은 적 수, 동률, 죽은 적 제외, 전투 포기와 빈 목록을 독립 검사한다. Unity Mac 빌드와 앱 서명을 확인한다. 작은 화면과 실제 Mac·Windows 결과 화면의 글자 가독성 및 조작은 별도 확인이 필요하다.

## 추가 작업: 복원 시점에 맞는 패배 안내

패배 순간의 자원과 웨이브 시작 시점의 자원은 다를 수 있다. 복원이 가능하면 결과 카드의 골드·빈 자리·추천을 실제로 복원할 웨이브 상태 기준으로 표시한다. 복원할 상태가 없으면 패배 시 골드로 구매를 권하지 않고 새 전투에서 편성을 바꾸도록 안내한다. 웨이브 복원과 준비 복원, 복원 없음에 대한 독립 검사를 추가했다. 실제 화면 가독성과 Windows 빌드는 별도 확인이 필요하다.

## 추가 작업: 전투 종료 후 웨이브 예고

패배 화면에 다음 웨이브·대장 예고가 남아 진행 가능한 것으로 오해할 수 있어, 승리와 패배 후에는 예고를 숨긴다. 준비·전투 중에는 기존 예고를 유지한다. 격리된 Web 테스트의 패배 fixture에서 기존 현상을 확인했다.

## 추가 작업: 남은 적에 맞는 힌트

100명 도달로 패배했을 때 한 종류가 가장 많이 남았다면 그 적의 특성에 맞는 짧은 편성 힌트를 표시한다. 힌트는 선택지 제안이며 패배 원인이나 승리 보장은 아니다. 최다 수가 같거나 전투 포기라면 특정 적을 지목하지 않고 복원 자원 기준 안내를 유지한다.

## 추가 작업: 기술자 지원 안내

기술자 배치 미리보기는 범위 안의 공격 병력 수를 보여준다. 여러 기술자의 공격 속도 지원은 더해지지 않고 가장 높은 값만 적용되므로 이 점을 미리보기와 도움말에 명시한다. 전투 수치와 기존 지원 계산은 변경하지 않는다.

## 추가 작업: 패배 안내 검사 연결

기존 격리 화면 검사는 예전 별도 추천 함수를 확인하고 있어 결과 카드의 최신 추천과 달라질 여지가 있었다. 검사도 실제 결과 카드가 사용하는 추천 규칙을 호출하도록 연결했다.

## 다음 우선순위

1. **병과·자리 선택 안내:** 적의 약점과 사거리, 빈 자리가 어떤 병과에 유리한지 전투 중 더 명확히 전달한다. 기존 추천을 먼저 실제 화면에서 확인하고 부족한 부분을 개선한다.
2. **패배 후 재도전:** 웨이브 복원 시 골드·편성이 시작 시점으로 돌아간다는 점이 충분히 명확한지 확인한다. 실제 복원 상태에 근거해 조언이 필요한지 검토한다.
3. **마지막 소탕:** 6배 소탕과 피해 없음 안내가 실제 플레이에서 적절한지, 사거리 밖 적을 찾기 쉬운지 확인한다.
4. **난도와 배지:** 임시 배지 기준과 병과 조합의 난도를 사람 플레이 및 여러 전략·시드로 재검토한다. 단일 자동 전략의 승패만으로 수치를 변경하지 않는다.
5. **손맛과 재도전:** 병과별 공격음, 경고·대장 처치의 체감과 전장 완료 후 동기를 점검한다. 추가 모드는 현재 한 판의 재미 검수 후 결정한다.
