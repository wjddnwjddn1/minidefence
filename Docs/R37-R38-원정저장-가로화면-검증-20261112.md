# r37-1 원정 저장·화면 / r38 가로 전용 검증

2026-11-12 · Codex · Unity6000.6.7f1 · Windows · 원격119426c 기반.

## 적용 범위

Claude가 구현한 원정 코어(`abc33e9`)와 미커밋 화면을 이어서 마무리했다. 새 세션 저장과 포기 처리, 좁은 화면 원정 진입/온기 표시가 r37-1 범위다. 도중에 받은 r38 지시에 따라 세로 전투 화면 개선을 폐기하고 가로 전용·낮은 가로 화면 배치를 적용했다. 기존 원정 준비9종의 값·위협·온기 소모·빙결 M 수치는 변경하지 않았다.

- 원정 세션: `ExpeditionSessionData`에 원정 상태·시작 여부·전투/준비 JSON·속도를 함께 저장한다. Unity의 null 인라인 클래스 확장을 피하려고 중첩 전투는 문자열 JSON으로 보관한다. 원정 세션은 자유 전투 저장과 별도 키다.
- 즉시 시작 저장, 전투 중 약1초 간격, 앱 정지·종료 저장. 이어가기는 정지 상태다. 이탈·자유 전투 왕복 후에도 저장한 전투를 사용한다. 시작 저장 실패는 준비로 돌리고 실패 알림을 표시한다. 시작한 원정의 저장이 없거나 손상되면 준비부터 재도전하지 않는다.
- 포기는 `Lost`로 유지하고 기록한다. 야영지 포기는 이미 지킨 전장을 완료 수에 포함한다. 이전 run-only 저장의 Battle 상태는 시작 여부를 확인할 수 없어 종료 처리한다. Camp/Won/Lost는 이관한다.
- 높이480 미만 가로 화면의 막대는 각각44px다. 전장 높이는 844×390에서286px, 740×360에서256px로 기존보다48px 늘었다. 원정/메뉴는 위, 하단은 시작/호출 중심 행동이다. 고리 메뉴·경고·이야기 위치를 새 막대에 맞춘다.
- 세로 화면은 회전 안내를 표시하고 입력과 전투 진행을 막는다. 기존 세로 전용 테스트4개는 폐기 이유를 적고 LandscapeWeb으로 연결한다. 다른 기존390×844 사례는740×360으로 옮겼다.
