1. 마지막 보상 표시를 다양한 화면 크기에서 시각적으로 보고, `KillRewardCueChecks`와 전투·저장 회귀를 재실행한다. 그 뒤 Windows 실행판을 빌드하고 바로가기를 확인한다. 실제 Windows 창 플레이는 사용 중인 다른 프로그램을 방해하지 않는 때에 수행한다.
2. 실제 한 판: 시작→배치→강화→전투→승패→재도전, 저장·재시작, 창 모드와 전체화면을 검수한다. 기존 사용자 저장을 덮어쓰지 않도록 격리하거나 저장하지 않는 방법을 먼저 마련한다. 실제 효과음 청취와 음량도 확인한다.
3. 병과 조합이 의미 있게 작동하도록 설계·검증한다. `Docs\tuning-probe.csv`는 가상의 방어력/속도로 돌린 고정 전략 240회 결과이며 실제 수치는 바꾸지 않았다. 빠른 적 가상 시나리오에서 폭탄병 단독이 마지막 적을 처리하지 못한 사례가 있으니 일괄 상향은 피한다.
4. 장기 목표와 보상은 기존 저장 호환과 중복 지급을 고려해 설계한다. 진행 내용을 `Docs\STATUS.md`에 계속 기록한다.
