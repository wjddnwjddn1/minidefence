# Claude에게 전달 — 현재 작업과 앞으로의 방향

작성: Codex · 2026-11-06

## 요청

지금까지의 변경을 독립적으로 검토하고, 실제 게임 상태에 맞춰 다음 작업의 우선순위를 정해 주세요. 이 문서는 작업 인계이며 Claude가 검수했다는 뜻은 아닙니다. 확인한 결과와 미확인 사항은 `Docs/CLAUDE-REVIEW.md`에 남겨 주세요. 엔진 코드 수정은 사용자 지시에 따라 Codex가 담당합니다.

작업 전 `AGENTS.md`, `README.md`, `PRODUCT.md`, `Docs/게임성_작업방향.md`, `Docs/CLAUDE-DIRECTION.md`, `Docs/CLAUDE-REVIEW.md`, `Docs/STATUS.md`, `Docs/CODEX-HANDOFF.md`의 최신 내용을 확인해 주세요. 기존 방향 지시서의 r번호와 오래된 TODO는 당시 지시이므로 현재 코드와 최신 작업 기록을 대조한 뒤 적용해야 합니다. 같은 파일을 다른 세션이 수정 중일 수 있으니 쓰기 직전에 다시 읽고 변경을 보존해 주세요.

## 게임과 목표

Unity 6000.6.7f1 기반 2D 디펜스 게임입니다. 적이 동시에 100명에 도달하면 패배하며, 플레이어가 병과와 위치, 강화와 호출 시점을 선택하고 패배 후 편성을 바꿀 이유를 이해하도록 만드는 것이 목표입니다. 검사·궁수·폭탄병·서리·기술자와 세 전장, 세 난도, 별도 증원 전투가 구현되어 있습니다. 실제 동작과 세부 규칙은 README와 코드를 기준으로 확인해 주세요.

## 최근 Codex 작업

- **출정·배치:** 넓은 출정 화면의 글자 크기와 간격을 개선했습니다. 기술자 배치 미리보기에서 새로 지원할 병력과 이미 지원 중인 병력을 구분하고 작은 가로·세로 화면에도 안내를 표시했습니다.
- **마지막 소탕:** 마지막 적 등장 안내를 2초 동안 강조하고 이후 남은 적과 최대 적 수를 표시합니다. 공격 병력이 없을 때와 사거리 확인이 필요할 때 정체 안내를 구분합니다. 마지막 적이 등장해도 공격 병력 판매나 사거리 문제로 소탕이 멈출 수 있으므로 승리를 확정한다고 표현하지 않습니다.
- **전투 결과:** 승패 후 사용할 수 없는 속도·강화·판매·표적 등의 버튼을 해당 결과 화면에서 숨기고 다음 전장과 재도전을 유지했습니다.
- **저장 실패 복구:** 증원 선택 직전 자동 저장 실패 시 재시도 버튼이 사라지는 문제를 수정하고, 같은 카드 선택지로 복원되는지 검사했습니다. 일반 자동 저장 실패는 수동 또는 후속 자동 저장 성공까지 경고합니다. 수동 저장 성공·실패와 잔불 조준/예약 때문에 저장할 수 없는 상태도 버튼에 표시합니다.
- **소리:** 마지막 소탕 선율을 합성 음악에 추가하고 생성 중 반복 배열 할당을 줄였습니다. 소리 설정과 병과별 재생 이벤트를 자동 검사했습니다.
- **작업 환경 정리:** Codex가 Downloads에 만든 임시 스크린샷·검사 파일 101개를 정리했습니다. 과거 기록에서 Downloads를 가리키는 캡처는 더 이상 없으며, 프로젝트 내부의 기존 캡처와 사용자 파일은 유지했습니다.

세부 내용은 `Docs/STATUS.md`와 `Docs/CODEX-HANDOFF.md`의 최신 기록 및 Git 이력을 참고해 주세요. 최근 주요 커밋은 `315c432`(마지막 적 안내), `d6cc445`(정체 안내), `5ccd7ad`(결과 버튼), `a961119`(증원 저장 재시도), `88283ef`(자동 저장 경고), `ff5770a`(수동 저장 결과), `1d4a00b`(조준 중 저장 안내)입니다.

## 검증된 범위와 한계

- 최종 격리 Web 자동 전투에서 성문 10웨이브 승리, 최대 적 39명, 처치 179명, 브라우저 오류 0건을 확인했습니다. 핵심 전투 199건, 소탕 저장·복원 36건, 전투 저장·손상 검사 6,282건, 증원 선택 복원 전투 12판도 통과했습니다.
- 저장 실패는 격리 Web 실패 주입으로 재현하고 재시도와 화면 표시를 검사했습니다. 변경별 Web·Windows 빌드도 통과했습니다. 세부 크기와 검사 근거는 상태 기록을 확인해 주세요.
- 자동 조작과 수치 검사는 사람의 재미·난도·가독성 평가가 아닙니다. 실제 Windows 한 판과 저장소 장애, 사람의 소리 청취·음량 균형, 실물 터치 조작은 확인되지 않았습니다. 기존 Claude 검수는 해당 기록에 적힌 시점과 범위에만 적용하며, 이후 변경의 독립 검수로 간주하지 않습니다.

## 앞으로의 우선순위 제안

1. **현재 빌드 독립 검수:** 최신 코드와 실행판을 확인하고, 저장 실패 안내·증원 선택 복원·결과 화면·소탕 안내가 실제 상황과 작은 화면에서 이해되는지 살펴봐 주세요. `CLAUDE-REVIEW.md`의 이전 지적은 최신 상태와 대조해 해결/미해결/재확인 필요를 구분해 주세요.
2. **실제 플레이 관찰:** 가능하면 Windows 실행판에서 첫 진입부터 배치, 강화, 조기 호출, 패배 후 복원 또는 승리까지 한 판을 확인합니다. 사람의 조작과 소리 청취가 불가능하면 그렇게 명시하고 사용자에게 필요한 확인 항목만 전달합니다. 저장 데이터는 보존합니다.
3. **선택의 이해도:** 병과·자리·사거리와 기술자 지원, 패배 후 복원 시 골드와 편성 변화가 화면만으로 이해되는지 확인합니다. 문제를 발견하면 재현 조건과 기대 동작을 제시하고, 기존 상태에 근거하지 않는 승리 보장 표현은 피합니다.
4. **소탕과 전투 리듬:** 6배 소탕, 피해 없음 안내, 병과별 공격음과 경고음이 실제로 구별되고 적절한지 확인합니다. 자동 시험만으로 체감이나 음량 승인을 내리지 않습니다.
5. **난도·배지와 신규 콘텐츠:** 사람 플레이 기록 및 여러 전략·시드의 비교를 모은 뒤 난도와 배지 기준을 검토합니다. 새 모드나 큰 수치 변경은 현재 한 판의 재미와 문제를 먼저 확인한 후 결정합니다.

발견 사항은 심각도, 재현 조건, 기대/실제 동작, 확인한 빌드와 화면 크기, 근거 및 미확인 범위를 적어 주세요. 수정 제안은 가능한 한 작은 단위로 나누고 저장 호환성·전투 결과 결정성·기존 데이터에 미치는 영향을 함께 표시해 주세요.

## 협업 및 보존

- 사용자와 한국어로 소통하고 텍스트는 UTF-8로 읽고 씁니다. CP949/ANSI는 사용하지 않습니다.
- 실제 코드는 `Assets/Scripts/`, 검사는 `Tests/`입니다. 기존 게임과 문서, 다른 세션의 변경 및 사용자 저장을 보존합니다. 작업 트리에 기존 미커밋 변경과 추적되지 않는 파일이 많으므로 임의로 정리하거나 되돌리지 않습니다.
- 웹판과 `C:/퍼블리싱/htdocs`는 읽기 전용이며 사용자 요청 없는 외부 배포는 하지 않습니다. 검사 결과와 실제 사람의 평가를 분리합니다.
- Claude는 검토 내용을 `Docs/CLAUDE-REVIEW.md`에 기록하고, Codex는 구현·검증·미해결 사항을 `Docs/STATUS.md`와 `Docs/CODEX-HANDOFF.md`에 기록합니다. 문서만으로 세션 간 자동 전달이나 동시 검수가 이뤄지는 것은 아닙니다.
