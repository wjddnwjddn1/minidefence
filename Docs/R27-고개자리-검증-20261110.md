## 구현과 호환

- 기존0~7번을 보존하고8번(640,548),9번(704,452)을 끝에 추가했다. 공유 `Balance.Fields[2].Slots`를 수정하지 않고 후보 `FieldDef`를 따로 만든다.
- `Battle.FieldFor`로 규칙·모드에 맞는 전장 정의를 선택한다. 출정 미리보기와 실제 전투가 같은 선택 함수를 사용한다. 배치 등급/추천 캐시는 전장 번호만이 아닌 실제 전장 정의별로 분리했다.
- 준비/전투 저장 검증은 규칙과 모드에 맞는 자리 수를 확인한다.10병력 저장·복원·전투 복사 후 진행을 검사했다. 구 규칙/증원으로 추가 자리를 가져오면 거부한다. 추가 자리에 병력이 있는 상태에서 증원 전환도 부작용 없이 거부한다.
- 배지 한도는 기존80/90/90을 유지한다. 자리 추가를 이유로 기준을 완화하지 않았다.
- **화면에서 확인한 설계 수정:** 요청 좌표 그대로 배치하면 성채 그림과 병력이 겹쳤다. 자리·경로·능력치는 유지하고 후보의 성채 그림 원점만(512,400)→(480,340)으로 옮겼다. 기존 규칙/증원의 그림은 그대로다. 건물에는 충돌·공격 판정이 없다.
