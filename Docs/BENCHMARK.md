# 디펜스 게임 비교와 적용 방향

2026-10-29. 공식 소개와 게임 매뉴얼을 읽고 비교한 설계 조사이며 직접 플레이한 평가는 아니다.

- [Kingdom Rush](https://play.kingdomrush.com/kingdom-rush): 병과의 특수 능력과 조합을 비교했다. 잔불의 성채의 검사·궁수·폭탄병·서리·기술자는 서로 다른 역할과 3단계 분기를 가진다.
- [Legion TD 2 매뉴얼](https://beta.legiontd2.com/manual/): 웨이브별 공격·방어 특성과 미리 아는 적 구성을 비교했다. 다음 적 종류와 수를 보여주고 배치 계획에 활용한다.
- [Bloons TD 6 조작 가이드](https://help.netflix.com/en/node/718990757024356): 타워 배치와 업그레이드 경로를 비교했다. 강화 단계의 색상, 사거리, 선택 분기를 전장에서 알아볼 수 있게 한다.
- [Random Dice: Defense](https://apps.apple.com/us/app/random-dice-defense/id1462877149): 강화와 주기적인 보스 웨이브를 비교했다. 기존 전장의 대장 등장과 병과 분기를 활용한다.
- [Defense Task Force](https://store.steampowered.com/app/720270/): 적의 속도·방어·특수 능력과 목표 우선순위를 비교했다. 궁수와 서리의 목표 선택, 적 종류 예고를 유지한다.
- [Crystal Tower Defense 개발 소식](https://store.steampowered.com/news/posts/?enddate=1693244855&feed=steam_community_announcements): 다음 웨이브의 방어 특성을 미리 알려주는 방식을 비교했다. 방패병과 대장 출현을 다음 웨이브에 강조한다.
- [The Gate Must Stand](https://store.steampowered.com/app/3975750/The_Gate_Must_Stand_A_Tower_Defense_Survivor/): 병력별 강화와 주기적 보스라는 진행 구조를 조사했다. 기존 대장 출현과 분기 선택의 의미를 더 잘 드러내는 방향으로 활용한다.
- [Factorio 웨이브 방어](https://wiki.factorio.com/Wave_defense): 전투 중에도 자원을 써서 즉시 방어를 개선하는 흐름을 조사했다. 잔불의 성채도 전투 중 배치·판매·강화와 일시정지 후 편성 조정을 제공한다.
- [Flux Tower Defense](https://store.steampowered.com/app/4645330/): 전투 종료 후 생존·처치 등 결과 요약을 참고해 한 판의 최대 적 수와 처치 수를 표시한다.

반복 진행은 살아남은 적과 다음 웨이브가 겹치도록 32초 자동 웨이브를 사용한다. 현재 고정 배치 자동 전략 36회에서 전부 승리했고 최대 적 수는 36이었다. 사람의 실력이나 재미를 입증하는 결과는 아니며 직접 플레이에 따른 난이도 검토가 필요하다.
