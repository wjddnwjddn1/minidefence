# r29 Windows 후보 갱신·입력 검수 — 2026-11-10

기준 `c77ec7b`: Claude34차의 고리 메뉴와 카드/메뉴 드래그를 Windows 작업 트리에 반영한 뒤 검수했다. 전장·웨이브·병과 수치와 기본 실행 규칙3은 바꾸지 않았다.

## 발견하고 고친 문제

1. **320×300 설명 카드 가림:** 원래 설명 카드가 맨 위 병과 버튼을 덮었다. 높이400 미만에서는 고리를 위쪽에 배치하고 설명 카드를 아래에 둬 선택 버튼과 분리했다.
2. **작은 닫기 영역:** 320 창에서 닫기가27.2px였다. 검사 창 기준 최소44px로 늘렸다. 둥근 버튼은 실제 원 내부로 클릭을 판정하고, 원끼리 겹치지 않는지 검사한다.
3. **Esc 뒤 카드 구매:** 카드를 끌다가 Esc를 누르고 놓으면85G가 차감되고 궁수가 배치됐다. Esc에서 드래그·GUI 클릭 소유·지도 클릭 상태를 함께 취소해 놓더라도 구매되지 않게 했다.

판정 실패 화면을 포함한 전후 근거와 실제 입력 로그는 `r29-windows-evidence/`에 있다. 검정/보라 분기와 기존 판매2회 확인은 유지했다.
