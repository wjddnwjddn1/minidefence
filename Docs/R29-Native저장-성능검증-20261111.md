작성: 2026-11-11 KST. 기준: Claude 35차 `b7c7982` + 이번 Codex 변경. Codex 자체 검사이며 이번 변경의 Claude 독립 검수는 아직 없다.

## 판정과 실제 수정

**저장 복원 버그 수정 PASS. 가로 화면 포함 Web 입력 26/26 PASS. Windows 렌더링 성능·입력 지연은 NR. r29 전체 완료 아님.**

실제 Unity Windows 개발 실행판에서 `CombatStore.Save(battle, null, 1)`이 `Invalid combat values`로 실패했다. `JsonUtility`가 비어 있는 인라인 체크포인트를 기본값 객체로 복원해, 유효한 체크포인트로 가져오려던 것이 원인이다. 최초 실패 메시지는 `r29-native-evidence-20261111/before-fix-failure.txt`에 보존했다. 최초 숨김 실행의 렌더링 표본은 유효하지 않아 성능 자료에서 제외했다.

`CombatSaveData.IsAbsent`로 null 또는 정확한 빈 객체 형태만 선택적 체크포인트 없음으로 취급한다. 현재 전투는 계속 필수로 검증한다. 값이 하나라도 들어 있는 잘못된 체크포인트는 정상적인 검증 과정에서 거부한다. 저장 키·버전·전투 규칙·가격·웨이브 수치는 바꾸지 않았다.

## 실제 Windows 저장·재개

- 이 실행 1회의 저장 3.7972ms / 불러오기 0.8534ms. 반복 분포·디스크 장치 간 성능을 뜻하지 않는다.
- QA 제품의 별도 PlayerPrefs만 사용하고 성공·실패 종료 시 검사 데이터를 지운다. 일반 제품과 후보 제품의 저장은 사용하지 않는다.

자료: `r29-native-evidence-20261111/native/`의 JSON·CSV와 전후 상태. 원본 실행 디렉터리 UTC 식별자는 `20261110-175908-812`다.

## 재현 명령

저장·CPU 검사만 실행(기본 숨김):

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.6.7f1/Editor/Unity.exe' -batchmode -quit -projectPath C:/minidefence -executeMethod EmberBastion.Editor.ComparisonBuild.PerformanceQA -logFile C:/minidefence/Tests/bin/performance-build.log
```

Unity GUI 실행 파일은 셸에 따라 즉시 반환할 수 있으므로 빌드 종료와 로그의 성공을 확인한 뒤 실행한다. 실제 창을 표시하는 검사를 사용자가 허용한 뒤에는 `Run-NativePerformance.ps1 -Visible`을 사용한다. 다른 빌드·브라우저 검사와 동시에 돌리지 않는다. Windows 프로세스 실행 규칙상 명시적인 표시 허용 전에는 `Start-Process`를 Hidden으로 실행해야 해서, 이번에는 표시 승인을 질문하고 의존하지 않는 검사를 진행했다. 응답을 승인으로 추정하지 않았다.

표시 검사는 1280×720 / 1920×1080, 선택 없음/병력 선택의 4그룹마다 적80~99명 900프레임을 모은다. 워밍업·리셋 인접 프레임을 제외하고 프레임 타이밍 timestamp를 중복 제거한다. 분석기는 창 표시·GUI 호출·유효한 GPU 표본을 확인해야만 프레임 수치를 보고한다. 유효한 4그룹 p95가 16.67ms를 넘으면 분석 명령은 실패한다. 자료 부족은 PASS가 아닌 NR이다. 입력 표본은 QA 자기 창에만 보내는 합성 P 키이며 실제 기기→화면 지연을 측정하지 않는다.

Unity 프레임 타이밍은 지연 도착하므로 정확히 같은 적 수 프레임의 GPU 비용으로 귀속하지 않는다. 근거: [Unity FrameTiming API](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/frametiming), [Frame Timing Manager](https://docs.unity.com/en-us/engine/6000.6/manual/analysis/graphics-performance-profiling/profile-rendering/frame-timing-manager/manager).
