# 잔불의 성채 — 이야기 설정과 대본

2026-11-11. 사용자 지시: "게임 시작, 중간중간에 스토리 넣는 걸로 하자. 왜 적이 공격을 하고 그런 거부터 시작해서 캐릭터 간에 대화도 넣고, 적 몬스터에 대사를 넣어도 되고."
대사 원문은 `Assets/Scripts/Presentation/StoryScript.cs` 하나에 모았다. 문구를 고칠 때는 그 파일만 바꾸면 된다.

## 세계와 갈등
- 겨울이 끝나지 않는 골짜기에 성채가 있다. 성채의 화덕에는 마지막 불씨 **잔불**이 탄다. 잔불이 꺼지면 골짜기가 얼어붙는다.
- **고블린이 공격하는 이유:** 북쪽 고블린의 땅은 지난겨울에 통째로 얼어붙었다. 대장 **그르낙**은 잔불을 빼앗아야 부족이 산다고 믿고, 마을 전체를 이끌고 내려온다. 그들이 든 횃불은 꺼져 가는 불이다.
- 사람들은 고블린이 골짜기를 태우러 온다고 생각한다. 세린만 처음부터 진짜 사정을 안다.
- **결말(습지 나루 첫 승리):** 그르낙이 "불씨 하나면 됐는데"라고 말한다. 브론이 "잔불은 나눠 붙여도 줄지 않는다"며 불씨를 나루 건너로 보낸다. 마지막 문장은 "골짜기 너머에는 아직 꺼지지 않은 겨울"로 끝나서 이후 확장 여지를 남긴다.

## 어디에 나오나
| 시점 | 방식 | 내용 |
|---|---|---|
| 첫 실행의 첫 준비 | 대화창(클릭/Space로 넘김, Esc로 건너뜀) | 오프닝 6줄 |
| 각 전장의 첫 준비 | 대화창 | 전장 소개 2~4줄 (성문/숲길/고개/습지) |
| 습지 첫 승리 | 대화창 | 엔딩 5줄 |
| 1웨이브, 중간 웨이브, 마지막 웨이브 | 전투 중 하단 말풍선(4.5초, 전투 안 멈춤) | 아군 한마디 |
| 대장 등장 / 대장 보호 함성 | 하단 말풍선 | 그르낙 대사, 세린의 대응 조언 |
| 성채 피해(20초에 한 번) / 적 70명 | 하단 말풍선 | 브론 / 미라 |
| 승리 / 패배 | 하단 말풍선 | 전장별 한 줄 |
| 전투 중 5~9초마다 | 적 머리 위 작은 말풍선(2.4초) | 횃불병·질주병·방패병·폭약병 대사 각 4개 |

- 대화창은 준비 단계에서만 열리므로 전투를 멈추지 않는다. 한 번 본 장면은 `snomet.ember-bastion.story.v1.<id>` 기록으로 다시 나오지 않는다.
- 오프닝을 Esc로 건너뛰면 첫 전장 소개도 함께 건너뛴다.
- 적 대사의 무작위 선택은 화면 전용 난수(UnityEngine.Random)를 쓰고, 전투 난수는 건드리지 않는다.
- **자동 검사에서는 꺼진다:** `-smoke`/`-qa` 실행 인자, `--storage-only`, QA 제품, 그리고 개발 Web 빌드(URL에 `story=1`이 있을 때만 켜짐). 기존 검사 URL에는 `story=1`이 없으므로 전부 영향이 없다.
