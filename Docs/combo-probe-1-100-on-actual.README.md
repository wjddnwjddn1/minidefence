`combo-probe-1-100-on-actual.csv`는 현재 전투 엔진의 최신 기준 결과로 사용하면 안 된다. 2026-11-06 확인한 작업 트리 파일의 SHA-256은 `7B686BC1FC363CE97308418044D52EDE7F364FBADFFAD25244BE6F46376EBBF0`이며 기존 미커밋 변경이 있다. 파일의 정확한 작성 배경이나 사용자 변경 여부는 확인되지 않아 내용을 보존한다.

현재 엔진의 도전 난도·밀도 100·상성 묶음 적용 216판을 2026-11-06 별도 임시 경로에서 다시 실행한 결과의 SHA-256은 `9FD2B168AB217A4B15D24FDC0E120048F17D612AAF6FB2702EB4021E278A5A11`이다. 두 결과는 기준이 다를 수 있으므로 같은 실험의 재현 성공으로 비교하면 안 된다. 자동 전략의 결과는 사람의 재미·난도 평가를 대신하지 않는다.
