# 완성까지 남은 작업

1. **사람 플레이 검수:** Windows에서 신규 게임부터 승리·패배·자동 저장·웨이브 복원까지 직접 플레이하고 창 크기와 전체화면을 전환한다. 도움말·첫 판 안내의 가림과 조작을 확인한다.
2. **난도와 기록:** 신규 기본·도전의 적 밀도 및 배지 기준은 자동 정책으로 측정한 임시값이다. 사람 기록을 모아 여유 배지와 병과 조합의 재미를 재평가한다. 이전 저장과 기록 분리를 실제 사용자 데이터로 확인한다.
3. **손맛과 소리:** 대장 폭발, 흔들림, 위험 경고와 효과음을 Windows에서 직접 보고 듣고 조정한다. 많은 적이 있을 때의 프레임 속도와 배경음·소탕 선율의 음량 균형을 확인한다.
4. **UI 마감:** 버튼의 눌림·비활성 대비와 종이 이음새, 작은 화면의 긴 안내·결과 창을 실제 기기에서 점검한다. 전장 추천과 저장 실패 안내를 검증한다.
5. **재도전 동기:** 보급 카드나 끝없는 전장 등은 사용자 소감과 별도 실험 후 결정한다. 자동 테스트만으로 재미나 완성도를 확정하지 않는다.

자세한 조건·수치·검증 결과는 `STATUS.md`에 기록한다. 기존 웹판과 배포 폴더는 읽기 전용으로 유지한다.
