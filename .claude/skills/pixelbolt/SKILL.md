# Pixelbolt in this project

Use the pinned Pixelbolt source at `ThirdParty/Pixelbolt`, version 0.13.0, commit `04668a2f2f94e081d9b5f78889c075303bf04544`. Node.js 20+ is required. Read `ThirdParty/Pixelbolt/docs/agent-quick-start.md` and the relevant sections of `ThirdParty/Pixelbolt/skills/pixel-art/SKILL.md` before authoring. Run `node ThirdParty/Pixelbolt/bin/pixelbolt.js` from the repository root; do not use a floating `npx ...@latest` version. Work from editable recipes in `Art/Pixelbolt`, inspect output at actual game scale and document its source. `hero-sword.poses.json` is an upstream MIT example, not a final game asset. The sample `ember-guard` changes its palette and remains a prototype, not approved Tiny Swords quality. Preserve other sessions' work and do not replace game sprites without review. Pixelbolt atlas JSON is not the PixelFX metadata schema; do not use the PixelFX importer without a verified conversion. See `Docs/Pixelbolt.md` and `ThirdParty/Pixelbolt/LICENSE`.
