# 잔불의 성채 Unity 비교판

독립 Unity 2D 비교판이다. 성문 앞 방어선(10웨이브), 숲길 굽이와 바위 고개(각 8웨이브)를 지원한다. Windows 자동 실행과 로컬 Web 입력을 확인했다. 수동 플레이와 실제 휴대폰 검수는 [Docs/STATUS.md](Docs/STATUS.md)의 최신 기록을 따른다.

## 열기

1. Unity Hub에서 **6000.6.7f1**과 Web Build Support를 사용한다. 이 환경에서 설치와 로컬 라이선스 접근을 확인했다.
2. Hub에서 이 폴더를 기존 프로젝트로 추가하고 `Assets/Scenes/Comparison.unity`를 연다. 빈 2D 장면에서도 Play를 누르면 `BattleView`가 자동 생성된다.
3. 저장 장면은 메뉴 `Ember Bastion > Create comparison scene`으로 생성한다. 기존 장면을 덮기 전 변경사항을 저장한다.
4. `Build Windows playable`은 개발 표시가 없는 플레이용 실행판을, `Build Windows comparison`과 `Build Web comparison`은 검사용 개발 빌드를 만든다. CLI 진입점은 `EmberBastion.Editor.ComparisonBuild.WindowsPlayable`, `.Windows`, `.Web`이다.

전투 메뉴에서 효과음을 끔·작게·크게로 바꿀 수 있으며 설정은 비교판 전용 저장소에 유지된다. 도움말에서는 화면 흔들림을 켜거나 끌 수 있다. 효과음은 이 게임에서 직접 합성한다.

게임의 전투 메뉴 안 `도움말` 버튼에서 배치, 승패 조건, 잔불과 저장 방법을 확인할 수 있다. 도움말을 여는 동안 전투가 잠시 멈춘다.

게임을 실행하면 시작 화면에서 새 전투, 저장된 전투 이어하기, 준비 불러오기를 선택한다. 처음 시작할 때 배치부터 전투 시작까지 안내하며 건너뛰거나 도움말에서 다시 볼 수 있다. 웨이브 시작과 적 정리 때 별도 자동 저장을 만들고 승리·패배·포기하면 해당 자동 저장을 정리한다. 전투 이어하기는 정지 상태로 열리며 기존 저장을 지우지 않는다.

플레이용 실행판 `Builds/Playable/EmberBastion.exe`는 크기 조절이 가능한 창으로 시작한다. 요청한 `C:/ai로 만든 프로그램`의 기존 바로가기도 이 실행판을 가리킨다. Windows와 Mac 실행판에서 F11 또는 화면 전환 버튼으로 전체 화면과 창 모드를 전환할 수 있다. 전체 화면을 켜기 전의 창 크기는 창 모드로 돌아올 때 복원한다. 작은 가로 창에서는 `메뉴` 안에 전환 버튼이 있다.

검사65G·궁수85G·폭탄병105G·서리90G·기술자90G 중 병과를 고르고 빈 자리를 클릭한다. 선택 병력은 50G로 2레벨을 거쳐 90G로 3레벨 분기 둘 중 하나를 선택한다. 병력을 선택하면 지원 효과가 반영된 피해와 공격 간격을 볼 수 있다. 궁수와 서리의 목표는 앞선 적·강한 적·빠른 적·대장 우선으로 변경할 수 있다. 대장이 없으면 앞선 적을 공격한다. 기술자는 직접 공격하지 않고 주변 병력의 공격 속도를 높인다. 기술자만 배치한 경우에는 공격 병력을 추가해야 화면에서 웨이브를 시작할 수 있다. 3레벨에서 지원 범위를 넓히거나 주변 병력의 피해를 높이는 분기를 선택할 수 있다. 판매 버튼은 환급액을 미리 표시한다. 첫 웨이브 시작 전의 지출은 전액, 전투 중 투자분은 60%가 돌아온다. 전투 중에도 판매와 배치를 할 수 있다. 강화 단계별 병력의 원본 색상은 파랑·노랑·보라로 바뀐다. 병과 선택은 숫자 1~5, 시작은 버튼 또는 Enter, 정지는 P, 잔불 조준은 E/Space, 방향키 이동·Enter/Space 확정·Esc 취소다. 정지 중 잔불은 위치만 예약한다. 드래그는 타격하지 않는다. 전투 메뉴의 `전투 포기`를 4초 안에 두 번 누르면 패배 결과로 이동해 웨이브 복원 또는 새 판을 선택할 수 있다. 승패 뒤 재도전은 해당 전장의 시작 골드로 새 판을 만든다. 패배 뒤 `웨이브 다시`를 선택하면 최근 웨이브 시작 순간의 병력·골드·남은 적·등장 대기열을 복원하고 일시정지한다. 편성을 바꾼 뒤 이어갈 수 있으며 조기 호출도 해당 웨이브의 시작 상태로 복원한다. 전투 저장 시 최근 웨이브 시작 상태도 함께 보관한다. 전투 중 적을 클릭하거나 누르면 체력·방어력·상태 효과를 확인할 수 있다. PC에서는 빈 자리에 마우스를 올리고 터치 화면에서는 자리를 누르고 있어 사거리를 미리 볼 수 있다. 손을 떼면 배치하고 드래그하면 취소한다. 폭탄병의 붉은 원은 공격할 수 없는 가까운 범위다.

병력을 배치하기 전 화면 오른쪽 위의 전장 선택을 누르면 출정 준비 창이 열린다. 전장과 난도를 고르고 출정을 눌러 확정하며, 닫으면 변경을 취소한다. 넓은 화면에서는 전장 경로를 미리 볼 수 있다. 병력 배치 후에는 전장 변경이 잠기고 난도는 전투 시작 전까지 바꿀 수 있다. 승리 후에는 `다음 전장`도 사용할 수 있다. 성문·숲길은 200G, 바위 고개는 340G로 시작하며 이전 전장의 편성·골드·체력을 이월하지 않는다. 재도전은 같은 전장에서 다시 시작한다. 전장을 승리하면 완료 여부가 이 게임의 별도 저장소에 기록되며 전장 선택 화면에서 볼 수 있다. 이전 체력 기반 기록은 보존하지만 새 규칙의 완료 기록과 구분한다. 전장 선택은 자유롭고, 완료 기록에 따른 보급은 플레이어가 직접 선택할 때만 적용된다. 조준 중에는 게임 시간이 멈추고, 방향키로 16픽셀씩(Shift를 누르면 48픽셀씩) 이동한 뒤 Enter 또는 별도로 누른 Space로 확정한다.

승리 시 전투 중 최대 동시 적 수의 최저 기록을 전장·난도·시작 보급액별로 저장한다. 전장 선택에서 현재 조건의 기록을 확인한다. 이전 버전 기록은 보급 조건을 구분할 수 없어 별도로 표시하며 보존한다.

기본 난도로 전장 한 곳을 완료하면 출정 준비에서 **증원 전투**를 선택할 수 있다. 도전 난도의 적이 더 촘촘하게 등장하며, 3파와 6파 직전에 보유 병과에 맞는 증원 카드 세 장 중 하나를 고른다. 고른 효과는 이번 전투에만 적용되고, 카드 선택 중에도 자동 저장되므로 다시 불러오면 같은 선택지가 나온다. 최고 기록은 일반 난도와 별도로 저장한다.

전장 완료 기록은 다음 판의 선택형 보급을 해제한다. 각 전장을 기본·도전·극한 중 어느 모드로든 완료하면 전장당 20G(최대 60G)를 새 전투 시작 전에 전장 선택 창에서 한 번 받을 수 있다. 같은 전장을 여러 난이도로 완료해도 한 번만 계산하며, 보급은 받지 않고 시작할 수도 있다. 준비·전투 저장과 웨이브 복원은 받은 보급을 유지한다.

전투 메뉴에서 100G를 써 잔불을 한 번 강화할 수 있다. 집중은 피해를 50% 늘리고, 확산은 반경을 90에서 130으로 넓힌다. 선택은 해당 전투에서 유지되며 준비·전투 저장과 웨이브 복원에도 반영된다. 강화 선택창이 열린 동안 전투는 멈춘다.

적은 길을 한 바퀴 돌아도 사라지지 않고 계속 이동한다. 전장에 동시에 살아 있는 적이 100마리가 되는 즉시 패배한다. 처치한 적은 인원수에서 빠지며, 최종 웨이브까지 모두 처치하면 승리한다.

첫 웨이브 시작 전 상단 버튼 또는 전투 메뉴에서 기본 32초, 도전 22초, 극한 18초 간격을 선택할 수 있다. 도전 모드 적의 체력은 50%, 극한 모드는 80% 높다. 신규 기본·도전 전투는 대장을 제외한 적의 수가 이전 규칙의 1.25배이며 극한은 이전 밀도를 유지한다. 이전 전투 저장은 기존 규칙으로 이어지고 기록을 분리한다. 첫 웨이브 시작 후 선택한 게임 시간 간격마다 다음 웨이브가 자동으로 시작되며 이전 적은 계속 남는다. 다음 웨이브의 적 종류와 남은 시간이 표시되고 웨이브가 바뀔 때 보급 골드를 받는다. 첫 웨이브부터 1·2·3배속을 선택할 수 있다. 보스가 나오는 웨이브가 가까워지면 전장 위에 예고가 표시된다. 현재 웨이브의 적이 모두 등장한 후 `다음 호출`을 누르면 추가 골드를 받고 앞당길 수 있다. 남은 적과 다음 적 수를 확인한 뒤 4초 안에 다시 눌러야 실행된다. 적이 동시에 100마리에 도달하면 패배한다.

`준비 저장`은 현재 준비를 이 Unity 비교판의 별도 저장소에 기록한다. `준비 불러오기`는 게임을 새로 연 직후 같은 빈 준비에서 사용할 수 있다. `전투 저장`은 적과 대기열, 병력, 시간, 난수, 배속 및 웨이브 재도전 상태를 별도 슬롯에 기록한다. 게임을 다시 연 직후 빈 준비 화면에서 `전투 이어하기`를 선택하면 정지 상태로 복원된다. 준비 저장과 전투 저장은 서로 다른 슬롯이며 명시적으로 저장할 때만 갱신한다. 잔불 조준 또는 예약을 끝낸 뒤 저장할 수 있다. 웹 브라우저 데이터 삭제나 사이트 저장 제한에 따라 Web 저장이 지워지거나 실패할 수 있다.

## macOS 실행판

Unity 메뉴 `Ember Bastion > Build Mac playable (Universal)` 또는 CLI 진입점 `EmberBastion.Editor.ComparisonBuild.MacPlayable`로 프로젝트 상위의 `실행용/EmberBastion.app`을 만든다. Intel과 Apple Silicon 코드를 함께 포함하는 Universal 앱이며, Windows 실행판과 별도로 생성된다. Apple Silicon에서의 실제 실행은 해당 기기에서 확인해야 한다.

## 검증

`Tests/Run-CoreChecks.ps1`은 .NET Framework C# 컴파일러로 독립 전투 규칙을 컴파일하고 검사한다. `Tests/Compare-Web.mjs`는 로컬 웹판 모듈을 읽어 시드1의 60초 전투를 C# 실행과 대조한다. `Tests/Compare-Frost.mjs`와 `Tests/Compare-Mixed*.mjs`, `Tests/Compare-Strong*.mjs`, `Tests/Compare-Aggregate*.mjs`는 서리와 다른 병과의 편성을 각 전장의 웹 규칙과 대조한다. 공통 비교 코드는 `Tests/FrostParity.mjs`다. 이 비교 도구들은 이전 체력 기반 규칙의 기록이며, 100마리 패배 규칙을 적용한 현재 버전의 결과와 일치하지 않을 수 있다. `Tests/Compare-Smith.mjs`는 기술자 지원 효과와 분기를 세 전장의 웹 규칙과 대조한다. 웹판과 사용자 저장을 변경하지 않는다.

Unity 에디터의 `EmberBastion.Editor.TextureAudit.Run` 검사는 Resources 텍스처가 가져오기 과정에서 원본 크기와 달라지면 실패한다. 서리와 수리 시트는 2112픽셀 폭을 보존한다. 이 검사는 기기 GPU의 텍스처 크기 제한까지 보장하지는 않는다.

`Tests/Run-SimulationStress.ps1`은 여러 시드의 자연 골드 전투가 종료되는지와 전투 상태에 비정상 숫자나 범위 오류가 없는지 검사한다. `-Mode normal`, `-Mode fast`, `-Mode hard`로 난도를 선택한다.

`Tests/Run-StrategyReplay.ps1`은 시작 골드와 일반 보상만 사용하는 자동 전략을 찾고 기록된 배치·강화·잔불 사용을 재생해 각 전장의 승리를 확인한다. 실제 사람의 조작이나 난도 평가는 아니다.

`Tests/AutoPlayWeb.cjs`는 별도 브라우저 프로필과 개발 전용 자동 행동으로 성문 전장을 3배속 완주하고 다음 전장을 확인한다. 이 시험은 승리 기록을 쓰지 않으며 수동 플레이나 실제 기기 검증을 대체하지 않는다.

`Tests/WebSmoke.cjs`는 로컬 HTTP 서버와 격리 브라우저에서 전장 선택, 배치 및 화면 크기별 조작을 검사한다. `SMOKE_QUICK=1`은 빠른 확인이다. 개발용 Web 빌드에는 효과와 분기·승패 화면 및 작은 창 시간 검증을 위한 명시적 `fx-smoke=burn`, `fx-smoke=bomb`, `fx-smoke=enemies`, `fx-smoke=branch`, `fx-smoke=frostbranch`, `fx-smoke=win`, `fx-smoke=loss`, `fx-smoke=clock`, `fx-smoke=checkpoint`, `fx-smoke=repair`, `fx-smoke=autoplay` 쿼리가 있으며, `savewrite`/`saveread`를 제외한 테스트 상태는 메모리에만 생기고 저장하지 않는다. 저장 fixture는 격리 브라우저에서만 실행한다. 실제 기기 검증을 대신하지 않는다. `SMOKE_RECORD=1`은 별도의 격리 브라우저에서 시험용 승리 기록을 저장하고 다시 읽는 검사다.

## 경계

5병과와 각 3레벨 분기, 궁수·서리 우선순위 및 조기 호출을 구현했다. 캠페인 성장과 무한모드는 후속이다. 준비 저장은 Unity 비교판 고유의 PlayerPrefs 키 `snomet.ember-bastion.unity-comparison.preparation.v1`를 사용한다. 기본 완료는 `snomet.ember-bastion.unity-comparison.clear-count.v2.`, 도전 완료는 `snomet.ember-bastion.unity-comparison.clear-fast.v1.`, 극한 완료는 `snomet.ember-bastion.unity-comparison.clear-hard.v1.` 키를 별도로 사용하며 기존 웹판의 키를 읽거나 쓰지 않는다. 작은 가로 화면의 `메뉴`에서는 병력 판매·목표 변경·준비 저장·배속·다음 호출을 사용할 수 있고 메뉴가 열린 동안 전투 시간이 멈춘다.

Web 빌드는 압축을 끈 개발용이다. 로컬 HTTP에서 검증하며 상태는 `Docs/STATUS.md`에 기록한다. 한국어 글꼴로 나눔고딕을 포함했고 라이선스는 `Docs/NanumGothic-OFL.txt`에 둔다. WebGL2/WebAssembly 및 브라우저별 모바일 지원 조건은 [Unity 공식 문서](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-browsercompatibility.html)를 참고하며 실제 기기에서 재검증한다.
